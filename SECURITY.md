# Security Policy

## Supported Versions

Only the current major version is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. 

If you discover a security vulnerability, please do NOT report it by creating a public GitHub issue.

Instead, please send an email to **randy@example.com** with a description of the vulnerability and the steps to reproduce it. 

You should expect a response within 48 hours. If the vulnerability is accepted, we will work on a patch and notify you when it is released. We will also coordinate with you regarding the public disclosure of the vulnerability.
