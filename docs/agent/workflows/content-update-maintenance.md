# Content maintenance workflow (Workspace Workflow)

Use this when a tool, workflow, or implementation detail changes and existing articles may drift.

## Steps

1. Identify impacted articles (search by tool name, library, feature area).
2. Update content to match current behavior.
3. Update `updatedAt`.
4. Verify internal links still work.
5. If the change affects multiple articles, add/adjust a “related content” link.
6. If the change affects architecture/scope, follow `workflows/docs-sync-and-roadmap-alignment.md`.
