# Overall Philosophy

The design should feel like a hybrid between:

- Apple
- Linear
- Vercel
- Stripe
- Notion

NOT like:

❌ Bootstrap Resume

❌ Creative Agency

❌ Dribbble Landing Page

❌ Fancy Portfolio

The goal is:

> "A Senior Engineer who cares deeply about quality."

The design should communicate professionalism before personality.

---

# Design Principles

## Minimal

Every element must have purpose.

If something can be removed,
remove it.

White space is preferred over decoration.

---

## Premium

Use typography instead of graphics.

The page should feel expensive without looking luxurious.

---

## Data Driven

Every section should communicate measurable impact.

Example:

15m → 3m

0% → 100%

50%

8+ Years

Never use fluffy marketing language.

---

## Editorial Layout

Think magazine.

Not dashboard.

Large margins.

Readable paragraphs.

Strong typography hierarchy.

# AI Instructions

When generating UI:

DO

✓ Prefer whitespace over decoration

✓ Emphasize measurable achievements

✓ Use editorial spacing

✓ Keep animations minimal

✓ Maintain premium typography

✓ Show projects before skills if space is limited

✓ Make recruiter scanning possible within 10 seconds

✓ Prioritize readability over creativity

✓ Maintain consistent spacing system

✓ Make portrait feel integrated into the hero instead of a separate image

DON'T

✗ Use gradients everywhere

✗ Use glassmorphism

✗ Use neumorphism

✗ Use bright blue accents

✗ Use random illustrations

✗ Use excessive icons

✗ Use progress bars

✗ Use circular avatar

✗ Use generic stock photos

✗ Over-animate
