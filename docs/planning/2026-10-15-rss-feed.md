# RSS feed (Roadmap Phase 8)

Date: 2026-10-15
Scope: one RSS 2.0 feed per locale, feed autodiscovery, a visible footer link.
RSS is allowed by `docs/agent/rules/roadmap-scope-guardrails.md` and listed as
open in `docs/roadmap.md` Phase 8.

## Decisions

- **One feed per locale:** `/en/feed.xml` and `/id/feed.xml`. A feed has one
  `<language>`, and readers subscribe by language. No mixed-language root feed.
- **Format:** RSS 2.0 with an `atom:link rel="self"`. Widest reader support; no
  dependency needed for ~50 items.
- **Generation:** Route Handler `app/[locale]/feed.xml/route.ts` with
  `dynamic = 'force-static'` and `generateStaticParams` for `en`/`id`, so
  `next build` writes `out/{locale}/feed.xml` (static export supports GET Route
  Handlers marked force-static).
- **Items:** every published (non-draft) article in the locale, newest
  `publishedAt` first. Fields: `title`, `link`/`guid` (permalink), `pubDate`
  (from `publishedAt`), `description` (frontmatter description, not full body),
  one `category` per tag. Summary-only keeps the feed small and avoids rendering
  MDX outside the page pipeline.
- **Deterministic output:** `lastBuildDate` is the newest article `updatedAt`,
  not the build time, so unchanged content gives an unchanged file.
- **Autodiscovery:** `createPageMetadata` adds
  `alternates.types['application/rss+xml']` for the page's locale, so every page
  advertises its locale's feed.
- **Footer:** RSS icon next to the social icons (desktop and mobile), linking to
  the current locale's feed. Plain `<a>`, not `next/link`, because the target is
  not a page.

## Out of scope

Full-content feeds, Atom/JSON Feed, per-domain feeds, a custom content type
header (Cloudflare Pages serves `.xml` as XML already).

## Verification

- `./init.sh` (lint, build, smoke).
- Smoke check (`scripts/smoke.mjs`, no XML parser dependency): both feeds exist,
  start as RSS 2.0, declare the locale, item count equals the locale's article
  pages, every item link resolves in `out/`.
- One-off: both feeds parse with a real XML parser.
- Built HTML contains the autodiscovery `<link>` for the right locale.
- Playwright screenshots of the footer at 1440px and 390px.
