# Rules

## Architecture Rules

- Use Next.js App Router only
- Use TypeScript strict mode
- Prefer Server Components
- Keep architecture simple
- Avoid premature abstraction
- Keep file structure readable
- Minimize dependencies

---

## Forbidden Features (Initial Phases)

DO NOT ADD:

- authentication
- database
- Prisma
- Supabase
- Firebase
- CMS
- admin panel
- analytics
- search engine
- websocket features
- real-time systems
- Framer Motion
- excessive animations

---

## UI Rules

Design should feel:
- technical
- clean
- engineering-focused
- readable
- minimal

Avoid:
- glassmorphism
- giant gradients
- overanimated UI
- startup marketing aesthetic
- cluttered layouts

---

## Performance Rules

Prioritize:
- fast loading
- minimal JS
- Lighthouse >90
- semantic HTML
- accessibility
- mobile-first layouts

---

## Code Quality Rules

- strong typing
- reusable components only when necessary
- avoid magic numbers
- avoid giant components
- avoid unnecessary hooks
- avoid deeply nested folders

---

## Content Philosophy

The platform focuses on:
- engineering thinking
- experiments
- troubleshooting
- systems
- practical documentation

NOT:
- motivational writing
- generic tech news
- personal diary content
